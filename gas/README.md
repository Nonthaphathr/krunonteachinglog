# Teaching Log → Google Sheet + สรุปเข้า LINE ทุกเช้า 07:00

ระบบนี้ทำ 2 อย่าง
1. รับวิชา/บันทึกช่วยจำจากเว็บ Teaching Log เก็บลง Google Sheet ให้อัตโนมัติ
2. ทุกเช้า 07:00 ดูตารางสอนว่า “วันนี้สอนวิชาอะไร” แล้วส่งการ์ดสรุป “เนื้อหาที่บันทึกไว้ล่าสุด” ของแต่ละวิชาเข้า LINE (การ์ดเลื่อนซ้าย-ขวา 1 ใบ/วิชา เรียงตามคาบ)

> ข้อความที่ส่งเป็น LINE Flex Message (การ์ดแบบภาพ) ไม่ใช่ไฟล์ภาพ จึงไม่ต้องฝากรูปบนเซิร์ฟเวอร์ใด ๆ สีหัวการ์ดตามสีวิชาในเว็บ และนับเป็น 1 ข้อความต่อวัน

## ตั้งค่าครั้งแรก (ทำครั้งเดียว ~10 นาที)

### 1) Google Sheet + สคริปต์
1. สร้าง Google Sheet ใหม่ (ตั้งชื่อ เช่น `Teaching Log Data`)
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิม วางโค้ดจาก `gas/Code.gs` ทั้งไฟล์
4. (แนะนำ) Project Settings → ติ๊ก “Show appsscript.json” แล้วใช้ค่าจาก `gas/appsscript.json` หรืออย่างน้อยตั้ง Time zone เป็น `Asia/Bangkok`

### 2) LINE Official Account
1. ไป LINE Official Account Manager → Settings → **Messaging API** → Enable
2. เข้า [LINE Developers Console](https://developers.line.biz/console/) → เลือก Channel นั้น
   - แท็บ **Messaging API** → ออก **Channel access token (long-lived)** แล้วคัดลอก
   - แท็บ **Basic settings** → คัดลอก **Your user ID** (ขึ้นต้นด้วย `U…`)
3. เพิ่ม Official Account นี้เป็นเพื่อนในไลน์ของครูนนท์ (ต้องเป็นเพื่อนก่อนจึงจะ push ข้อความหาได้)

### 3) ตั้ง Script properties
Apps Script → **Project Settings → Script properties → Add**

| ชื่อ | ค่า |
|---|---|
| `LINE_TOKEN` | Channel access token |
| `LINE_USER_ID` | Your user ID (`U…`) |
| `SECRET` | (ไม่บังคับ แต่แนะนำ) รหัสลับที่คิดเอง เช่น `kru-non-2569` |
| `SEND_EMPTY` | (ไม่บังคับ) `true` = วันที่ไม่มีสอนก็ส่ง “วันนี้ไม่มีคาบสอน” |

### 4) รันตั้งค่า + ทดสอบ
1. เลือกฟังก์ชัน `setup` → Run (อนุญาตสิทธิ์) — สร้างชีต `Subjects` / `Notes` / `Log` และตั้งเวลาส่ง 07:00 ทุกวัน
2. เลือก `testPush` → Run — ไลน์ควรได้ข้อความ “ทดสอบ…”
3. **Deploy → New deployment → Web app** : Execute as = *Me*, Who has access = *Anyone* → Deploy → คัดลอก URL ที่ลงท้าย `/exec`

### 5) เชื่อมกับเว็บ Teaching Log
1. เปิดเว็บ → ไอคอนตั้งค่า → ส่วน **ภาคเรียนปัจจุบัน และการเชื่อม Google Sheet / LINE**
2. ใส่ภาคเรียน (เช่น `1/2569`), URL Web App, และ SECRET (ถ้าตั้งไว้) → **บันทึก** → **ทดสอบเชื่อมต่อ**
3. กด **ส่งข้อมูลทั้งหมดขึ้น Google Sheet** 1 ครั้ง (ส่งวิชา + บันทึกที่มีอยู่ตอนนี้)
4. เปิดชีต `Subjects` ตรวจว่ามีวิชา และคอลัมน์ `days` ถูกต้อง

หลังจากนี้ เพิ่ม/แก้วิชา และเพิ่ม/แก้/ลบบันทึกช่วยจำในเว็บ จะขึ้นชีตเองทันที

## ทดสอบการส่งสรุป
- เลือกฟังก์ชัน `sendBriefForDay` ใส่พารามิเตอร์เป็นวัน เช่น `'พ'` (ค่าที่ใช้ได้: จ อ พ พฤ ศ ส อา) → ส่งสรุปของวันนั้นเข้าไลน์ทันที
- หรือรัน `sendDailyBrief` เพื่อทดสอบตามวันจริง
- ดูผล/ข้อผิดพลาดที่ชีต `Log`

> ทริกเกอร์ของ Apps Script แบบ “ทุกวัน เวลา 7 โมง” จะยิงในช่วง 07:00–07:15 โดยประมาณ

## เปลี่ยนภาคเรียน (ไม่ต้องตั้งค่าใหม่)
1. เว็บ → ตั้งค่า → **ล้างข้อมูลรายวิชาทั้งหมด** (โหลดไฟล์สำรองให้ก่อน ภาคเรียนถัดไปตั้งให้อัตโนมัติ)
2. **ดาวน์โหลด template** กรอกรายวิชาใหม่ (รหัสวิชา · ชื่อวิชา · ชั้น/ห้อง · วันที่สอน · คาบ/เวลา · หน่วยกิต) แล้ว **นำเข้ารายวิชา**
3. ระบบส่งตารางสอนใหม่ขึ้นชีต `Subjects` ให้เอง, ตั้งเวลา/LINE/URL ไม่ต้องทำซ้ำ, รายชื่อนักเรียนดึงจาก “รายชื่อกลาง” ที่เคยนำเข้าแล้ว
4. ชีต `Notes` เก็บบันทึกทุกภาคเรียนไว้เป็นประวัติ (มีคอลัมน์ `semester`)

## โครงสร้างชีต
- `Subjects`: id, semester, code, name, room, days (เช่น `จ,พ`), period, credits, color
- `Notes`: id, semester, subjectId, subjectCode, subjectName, room, date, text, updatedAt
- `Log`: เวลา, เหตุการณ์, รายละเอียด (ไว้ตรวจปัญหา)

## หมายเหตุ
- วิชาที่ไม่ได้ใส่ “วันที่สอน” จะไม่ถูกส่งเข้าไลน์
- ถ้าวิชาไหนยังไม่เคยบันทึกเนื้อหา การ์ดจะขึ้นว่า “ยังไม่มีบันทึกเนื้อหาการสอนของวิชานี้”
- URL ของ Web App ควรเก็บเป็นความลับ และแนะนำให้ตั้ง `SECRET` เพื่อกันคนอื่นส่งข้อมูลเข้าชีต
- โควตาข้อความของ LINE Official Account ตามแพ็กเกจที่ใช้ — ระบบนี้ใช้ 1 ข้อความ/วัน
